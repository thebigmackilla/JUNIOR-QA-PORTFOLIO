# Junior QA Portfolio

Учебное портфолио начинающего специалиста по ручному тестированию (Junior Manual QA).

## О проекте

Практика тестирования учебного сервиса онлайн-записи на услугу.

## Материалы портфолио

- Чек-листы
- Тест-кейсы
- Баг-репорты
- Тест-дизайн: классы эквивалентности, граничные значения, таблица принятия решений и переходы состояний
- API testing и Postman

## Навыки

- Ручное тестирование веб-приложений
- Позитивное и негативное тестирование
- Smoke, Regression, Retesting и Exploratory testing
- Оформление дефектов и определение Severity/Priority
- Базовая работа с DevTools Network
- HTTP-методы, статусы ответов и JSON
- Основы SQL

**Примечание:** это учебный проект. Материалы не являются подтверждением коммерческого опыта или тестирования реального продукта.
