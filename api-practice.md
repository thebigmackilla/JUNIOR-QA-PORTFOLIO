# Практика API и Postman

Учебные заметки по HTTP-запросам и проверке ответов API.

## Что изучено на практике

- GET — получение ресурса.
- POST — создание ресурса.
- PUT — полное обновление ресурса.
- PATCH — частичное обновление ресурса.
- DELETE — удаление ресурса.
- Проверка кода ответа, тела ответа и JSON.
- Заголовок `Content-Type: application/json`.
- Базовые различия между аутентификацией и правами доступа.

## Примеры публичного API

Примеры используют JSONPlaceholder — публичный тестовый API для упражнений.

| Запрос | Ожидаемый статус | Что проверить |
|---|---:|---|
| `GET https://jsonplaceholder.typicode.com/posts/1` | 200 OK | Ответ содержит JSON-объект поста |
| `GET https://jsonplaceholder.typicode.com/posts/9999` | 404 Not Found | Несуществующий ресурс не возвращает найденный пост |

## Часто используемые HTTP-статусы

- **200 OK** — запрос успешно обработан.
- **201 Created** — ресурс создан.
- **401 Unauthorized** — данные аутентификации отсутствуют или не прошли проверку.
- **403 Forbidden** — сервер понял запрос, но доступ запрещён.
- **404 Not Found** — ресурс не найден либо сервер не раскрывает его наличие.

Статус оценивается в контексте контракта API: сам по себе код не доказывает корректность всей операции.

## План проверки POST

1. Указать корректный endpoint и метод POST.
2. Передать тело запроса в JSON.
3. Указать `Content-Type: application/json`.
4. Отправить запрос.
5. Проверить ожидаемый статус, структуру ответа и типы полей.
6. Если API поддерживает это, получить созданный ресурс отдельным GET.
7. Проверить негативные сценарии: отсутствующее обязательное поле, неверный тип данных и некорректный JSON.

## Авторизация и права доступа

Учебные сценарии:
- запрос к защищённому ресурсу без токена — ожидать 401, если это определено контрактом;
- запрос с валидным токеном, у которого недостаточно прав, — ожидать 403;
- после DELETE проверить результат отдельным GET, если это безопасно и поддерживается тестовой средой.

Не публикуйте реальные пароли, секретные токены или персональные данные в публичном репозитории.
